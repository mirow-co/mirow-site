### 2. Pesquisa de benchmarkers externos (2 agentes, resultados completos no chat)

**Autoridade de domínio** — conclusões que valem registrar:

- As escalas 0–100 **não são comparáveis entre si**: DR (Ahrefs) = só backlinks;
  DA (Moz) = ~40 sinais; AS (Semrush) = backlinks + tráfego + spam. Todas
  logarítmicas. Nenhuma é fator de ranking do Google.
- **DR 7 é plausível e não-alarmante** para consultoria B2B pequena sem link
  building (faixa típica do perfil: 1–15).
- **Nenhum checker gratuito responde por curl** — todos exigem navegador com JS ou
  conta. Endpoint free do Ahrefs (`api.ahrefs.com/v3/public/domain-rating-free`)
  devolve 403 sem API key (key sai de conta gratuita — decisão do Mario criar ou não).
- Checkers para rodar no navegador: `ahrefs.com/website-authority-checker`,
  `semrush.com/free-tools/website-authority-checker`, `moz.com/domainanalysis`.

**SEO/GEO** — roteiro de validação externa (~1h, tudo grátis):

1. PageSpeed Insights para `/pt/`, `/en/`, `/de/` (scores + CrUX de campo).
2. `validator.schema.org` + Google Rich Results Test nas mesmas URLs (JSON-LD).
3. SEOptimer ou Seobility na home (nota geral + módulo de AI visibility).
4. Ahrefs Free Backlink Checker + `site:mirow.com.br` no Google/Bing (indexação
   real × 106 URLs do sitemap).
5. Mentionable (mentionable.ai) para veredito GEO — não existe "PageSpeed do GEO"
   gratuito; o mercado (Otterly/Peec/Profound) é pago.
6. **Google Search Console** (exige verificação de propriedade) — é o gate G2 do
   Ponto de Vista e o dado que falta para qualquer conversa de presença orgânica.
