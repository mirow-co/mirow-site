## Decisões desta sessão

1. **`foundingDate` fora do schema.** Não é dado publicado, e o site diz 2012 e 2013 em lugares
   diferentes. A regra do handoff é "campo inventado é pior que campo ausente". **Pendência do
   Felipe.**
2. **A frase de sede não vai no hero.** Estourava a dobra exata em 31px (V01–V03/V30). Abre a
   seção de expertise, abaixo da dobra. E vai **sem ponto final** na home (V31, onda 58).
3. **Produção sem a frase de sede.** O Mario disse "pode publicar", mas o fluxo do projeto manda
   mudança de posicionamento passar pelo Andreas. Publiquei 59+60 sem ela. **Reversível: é um
   merge.**
4. **Minificar os bundles do tema: recomendação mudou para ESPERAR.** Com o desktop em 95, o
   ganho é só em celular fraco. O CrUX vai dizer de que aparelho o visitante chega. Depende de
   decisão do Mario sobre a REGRA Nº ZERO.
5. **Placeholder transparente em vez de CSS para o 404.** Zerar `background-image` mataria o
   gradiente em 12 dos 22 seletores (gradiente também é `background-image`), e re-declarar
   copiaria valor do tema para o nosso CSS — "valores gêmeos". Como a textura nunca carregou, o
   placeholder é pixel-idêntico ao que está no ar.
6. **`aria-level` em vez de trocar `<h4>` por `<h3>`.** O CSS do tema estiliza `h4` **por tag**;
   trocar mudaria o visual.
7. **`alt=""` nas decorativas, nome real nos selos.** Para os 6 selos eu **abri as imagens e li**
   o que está escrito nelas, em vez de deduzir do nome do arquivo — um deles é `image-52.png`.
   Confirmar com o Mario (C6 no backlog).
8. **Não escrevi asserção-lint para a classe do `<h4>` literal.** Daria falso positivo: o
   `114_a11y_atributos.py` usa `<h4>` literal **de propósito**, para idempotência. A lição foi
   para o `CLAUDE.md` (erro 10), que é onde o projeto guarda esse tipo de coisa.
